# ResumeTitan - Lite

This is a rewrite of the ResumeTitan MERN stack app. The goal of this rewrite is to make a super fast, lightweight, and performant version of ResumeTitan while keeping the main features.

## Stack

### Backend

**C++20** will be used as the backend.

#### Requirements

- `nlohmann_json`
- `cpp-httplib`

### Frontend

The web page will consist only of plain HTML5, CSS3, and JavaScript. This will ensure the best load times and smallest memory footprint possible, for maximum optimization.

### Database

**SQLite** will be the database used for this project.
